# Hanif Mobile Care Solutions

Full-stack **MERN + Next.js** monorepo for a mobile/electronics business combining **e-commerce sales and professional repair/service operations**.

## Structure
- `client/` — Next.js frontend
- `server/` — Express/MongoDB backend
- Root docs — architecture and project conventions

## Scope
### E-commerce
Products, categories, search, product details, cart, wishlist, checkout, orders, payments, shipping, inventory, coupons and reviews.

### Services
Repair/service catalog, service details, service booking, appointments, repair tracking, service centers and technician management.

### Customer
Authentication, profile, addresses, orders, appointments, wishlist, notifications and settings.

### Admin
Products, services, categories, inventory, orders, payments, coupons, reviews, customers, appointments, technicians, service centers, shipping and settings.

This repository is intentionally **structure-first**. Business/UI implementation can be added later without restructuring the monorepo.
